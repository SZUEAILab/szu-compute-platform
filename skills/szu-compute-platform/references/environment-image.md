# 最低价初始化与环境镜像

## 实例与环境选择

按 [运行模式](../SKILL.md#先确定运行模式) 决定初始化或复用。筛选项目要求的 GPU、CUDA/架构、显存、内存，再选授权团队/集群的最低价可用套餐；没有适用资源时报告价格与缺项，不升级规格。CPU 实例只用于完全支持 CPU 的项目。

初始化按最低必要卡数及覆盖安装、dry-run、镜像保存的有界时长配置；认证、查重、公钥与 [挂载](storage-datasets.md) 通过后同步源码和依赖。

## 镜像与挂载的边界

| 内容 | 保存位置 |
|---|---|
| 解释器、依赖、系统库、CUDA 用户态库 | 镜像快照覆盖的非挂载文件系统 |
| 源码、数据、日志、结果、环境清单 | 持久化挂载 |
| 环境变量、设备可见性、资源规格 | 任务配置或启动脚本 |

检查解释器、链接、动态库和快照范围。挂载中的环境不纳入镜像内容；需随镜像复用的环境在非挂载路径构建并验收，不能直接移动带绝对路径的环境目录。

## dry-run 验收

从真实入口缩小样本、步数和评估规模，保留关键导入、所选计算设备上的计算、数据读取、前向与更新。使用原生 dry-run 参数前确认其覆盖这些步骤。

通过标准：退出码 `0`、目标进度完成、关键数值有限、日志和评估可读；使用检查点的项目还需实际恢复后执行前向或动作。保存命令、代码标识、依赖清单与产物；失败修复并重跑，通过前不转正式实验。

## 保存环境镜像

1. dry-run 通过且文件落盘后，排除临时凭据、私钥和 token。
2. 调用 [镜像 API](web-api.md#保存环境镜像接口)，指定源实例、仓库、权限、新标签；不覆盖使用中的版本。
3. 等待就绪，核对引用、ID、标签及接口返回的 digest，关联环境清单和验收结果。无 digest 字段时记录“接口未提供”。
4. 镜像与持久化产物均验收后，按既定安排停止源实例；失败保留恢复条件并报告。

制作期间遇 SSH banner 超时，先查准确镜像与源任务状态，不据此重复保存或重建实例。

## 后续实验复用

用完整镜像引用恢复挂载、数据版本与当前源码。该镜像首次用于后续实例时验收拉取、启动、依赖、所选计算设备、数据与最小运行，再扩大实验；在已安排实例上验收，不另开付费验证实例。只改源码时同步验证；依赖、解释器、CUDA/架构变化时制作新版本。
