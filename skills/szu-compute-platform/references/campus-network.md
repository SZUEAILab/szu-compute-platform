# 校园网与 VPN 诊断

## 判断接入状态

检查平台域名真实 DNS、目标路由、HTTPS 只读请求与 SSH 代理端口。Wi-Fi 名称、私网 IP、进程或客户端“在线”不能单独证明接入成功；不通过断开有效连接测试位置。

| 结果 | 动作 |
|---|---|
| 校园直连可达 | 复用直连 |
| SecureLink 路由可达 | 复用 VPN |
| 缺少校园/VPN 路由 | 报告外部网络前置条件，继续不依赖内网的准备工作 |
| DNS 或连接失败 | 按下表定位，不凭一次超时判定校外 |

本技能诊断并复用已有接入，不操作 VPN GUI、不猜测 VPN 私有接口。VPN 接入与 [CAS 二次认证](bita.md#web-api-认证流程) 分别验收。

## 失败分流

| 证据 | 检查 |
|---|---|
| 解析错误或 Fake-IP | 校园 DNS、代理 DNS 与 [绕过配置](proxy-bypass.md) |
| 真实地址仍不可达 | 目标路由、VPN 分流、访问权限、服务状态 |
| HTTPS 401/403 | 进入平台认证或权限诊断 |
| SSH 入口不可达 | 先核对任务及入口状态，再查路由与代理端口 |

只修改已定位的冲突，不卸载其他 VPN 或中断无关连接。
