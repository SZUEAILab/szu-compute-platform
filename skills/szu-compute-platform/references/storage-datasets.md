# 工作区与数据集挂载

## 存储分工

| 内容 | 来源与使用方式 |
|---|---|
| 工作区 | 有权使用的账号/团队文件存储目录，通常挂到 `/workspace`；可写，保留源码、环境清单、日志与产物 |
| 文件存储中的数据 | 已有或共享目录，挂到项目期望路径；原始数据优先只读，预处理和缓存写工作区 |
| 平台“数据集” | 数据集 API 中的资源及版本，在任务 API 请求中引用；核对资源权限和版本 |
| 运行环境镜像 | 保存解释器、依赖、系统库等非挂载文件，见 [environment-image.md](environment-image.md) |
| 容器临时文件 | 不视为持久化保证，需要保留的内容应写入挂载或纳入环境镜像 |

`mkdir -p /workspace` 不会建立平台挂载；目录存在也不证明持久化。文件目录、数据集资源和镜像分别配置，不能互相替代。

## 提交前配置

1. 在当前集群及授权账号/团队下查找可复用存储和数据集，检查权限、容量和版本，避免重复上传下载。
2. 为工作区选择真实源目录、容器路径与可写权限；为输入数据选择目录或数据集版本及相应挂载入口。目标路径取自项目配置或加载器，不固定源路径和挂载数量。
3. 核对 UID/GID、读写模式和目标路径重叠，避免遮住镜像必需文件；不要用全员可写掩盖配置问题。
4. 从当前创建 API 请求定义或 API 导出的 YAML 核对存储/数据集 ID、源目录、版本、目标和模式，不猜 schema。已有任务缺挂载时先确认能否修改，需重建时沿用本次创建范围。

## 容器内验收

通过 [SSH](remote-runtime.md#ssh-连接) 登录，把 `SZU_WORKSPACE` 设为实际工作区、`SZU_DATA_ROOT` 设为输入数据目录；如有多个挂载，逐项检查：

```bash
: "${SZU_WORKSPACE:?Set the container workspace path}"
: "${SZU_DATA_ROOT:?Set the container dataset path}"
findmnt -T "$SZU_WORKSPACE" -o TARGET,SOURCE,FSTYPE,OPTIONS
findmnt -T "$SZU_DATA_ROOT" -o TARGET,SOURCE,FSTYPE,OPTIONS
df -h "$SZU_WORKSPACE" "$SZU_DATA_ROOT"
stat -c '%U:%G %a %n' "$SZU_WORKSPACE" "$SZU_DATA_ROOT"
```

`findmnt -T` 可能返回根文件系统或父级挂载，需将实际挂载点、源与模式对应到平台配置。工具缺失时查 `/proc/self/mountinfo`。在工作区创建唯一小文件、写入读回后删除，只验证本次文件；输入数据只读检查。同时检查容量和配额。

## 数据集验证与路径适配

核对版本、层级、文件数量/大小，并实际打开代表性文件读取元数据或少量样本；压缩包存在不等于加载器能读取。按任务需要使用清单、完整或抽样校验，不为连接验收默认遍历全部大数据。

路径不符时优先修改挂载或项目配置；确需链接则确认源可读、目标不存在，不覆盖已有目录或有效链接。解压、预处理和运行缓存写入确认可写的位置。缺数据时先查挂载与权限，再决定传输。

通过文件存储 API 取得真实存储桶、对象路径及当前授权上传/下载方式，按协议传输；不使用浏览器或 bita。上传文件不自动登记数据集资源。已有实例时也可通过 SCP 写入已确认的持久化挂载，之后在容器内复核大小、必要校验值与可读性。

### 需要下载数据时

若实例可直接访问官方数据源，可直接下载到已确认挂载，避免先下载本机再重复慢速上传。比较当前链路后再选择 HTTP/API、SCP 或源站下载，不固定某一种一定更快。

大文件需要续传/分块时，先确认服务器返回 `206` 且 `Content-Range`、长度与请求一致，再采用适度并发和有界重试；返回 `200` 的完整文件不能当作一个分块拼接。下载先写本次专用临时文件，完成大小和所需哈希校验后再放入加载器使用路径，避免半文件被误认作缓存。存在已有文件时先核验或选独立版本目录，不盲目覆盖。

记录源 URL、版本、大小及 SHA-256；自算哈希用于后续一致性比较，不能冒称发布方提供的校验值。收集模型等产物时也核对远端和本机哈希，并保留对应配置与原始指标。

## 持久化与重建

运行前明确结果、检查点、日志和所需离线跟踪/缓存路径。一个 `save_dir` 不保证所有程序临时数据都落在挂载中。

重建记录存储源、目标路径、数据版本和结果位置，新任务恢复同一映射并重新验收。环境镜像不假定包含挂载内容，挂载虚拟环境也需检查基础解释器兼容性。删除任务不等于删除存储，存储清理单独处理。
